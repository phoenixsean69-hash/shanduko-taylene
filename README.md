# Shanduko Housing Cooperative Admin Portal

Vite + vanilla JavaScript + AdminLTE 4 + Bootstrap 5.

## Run locally

```powershell
cd C:\Users\nooklyweb\Desktop\Shanduko-web
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Included UI

- AdminLTE-style responsive shell with collapsible sidebar
- Dashboard overview
- Cooperative member registry
- New member record form (member, spouse, next of kin, beneficiary, photo placeholders)
- Central transaction processing with Admin Fees vs Development Fees routing
- Isolated Admin Fees ledger
- Isolated Development Fees ledger
- Audit and control timeline
- Light/dark toggle

The prototype uses data and terminology from the supplied June 2026 Shanduko Housing Cooperative proposal. It is a front-end prototype; the persistence/authentication/backend APIs are not connected yet.
